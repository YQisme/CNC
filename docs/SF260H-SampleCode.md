# SF-260H 与 SampleCode 分析说明

`SampleCode` 共约 **508** 个文件，是华中 HNC 风格的实机样例/调试程序库；和当前仿真里的 SF-260H（摇篮 A/C）高度相关，但轴命名并不一致。

## 总体结论

样例程序体现的是：**XYZ + 双转台五轴 + RTCP（G43.4）+ 倾斜面加工（G68.2/G68.3 + G53.1）**，并带大量固定循环、对刀/测量宏。

实机程序里倾斜轴几乎都写成 **B**，转台写成 **C**；仿真与内置示例则按 **A/C** 建模。

## 程序分类（按用途）

| 类别 | 数量级 | 代表 | 作用 |
|------|--------|------|------|
| 钻孔/攻丝循环 | ~99 | `G81 G17`…`G89` | 三平面 + 倾斜姿态下的固定循环 |
| 倾斜坐标系 | 17+6 | `G68.2 G83`、`G68.3 G73` | 3+2 定位后钻孔/铣削 |
| RTCP | 8 | `ORTCP_B/C/BC`、`RTCPB` | 刀具中心点控制下的 B/C 联动 |
| 测量 | 7 | `MeasMT_B0C0`、`MeasMT_B30C90` | 不同 B/C 姿态下测头宏 |
| 对刀/标定 | 7+25 | `MILL标定`、`CYC_TM_*` | 铣/车对刀仪标定与测长 |
| 轴自检/跑机 | 若干 | `O99999`、`跑机`、`Bzhou.txt` | 直线轴自检、B 轴步进、空跑 |
| 实件加工 | 少量大文件 | `单叶片T1.nc`、`OS_开粗_A01*` | CAM 输出的五轴曲面/侧面加工 |
| 其他 O/ptp/NC | 大量 | `O600x.ptp` 等 | 通用铣削、定位、工艺片段 |

## 五轴核心写法（样例共性）

典型链路是：

```text
姿态定位(B/C) → G43.4 H.. → G68.2/G68.3 IJK → G53.1 → 切削 → G49/G69/G80
```

例如 `G68.2 G83`：

- `B45` 先摆姿态
- `G43.4` 开 RTCP
- `G68.2 … IJK` 建倾斜坐标系
- `G53.1` 刀具法向对齐
- 再跑 `G83` 深孔循环

`ORTCP_BC` 更简单：只验证 RTCP 下 B/C 联动回转，不切削。

## 与当前 SF-260H 仿真的关系

- **运动学意图一致**：双转台倾斜 + 回转，再配合 RTCP / 3+2。
- **轴字母不一致**：SampleCode 主用 **B/C**（约 219 个文件含 B）；仿真解析与 UI 用 **A/C**（`parser` 只读 `A`/`C`）。
- **能力差距**：样例大量依赖 `G43.4`、`G68.2`、`G53.1`、`G65` 宏、`G1009`、华中主轴写法（如 `S1=… M103`）；内置演示 `sf260-5axis-pose` 只做了 A/C 姿态 + 简单 3+2 直线铣。
- **行程/坐标系**：不少程序坐标到几百毫米（如 `X800`、`Z1000`），更像 CNCX630 一类更大机床或机床坐标系调试，不能直接当 SF-260H（行程约 260³）的安全程序。

## 导入本地程序

仿真支持从本机导入程序（「程序」页或「程序库」页的 **导入**）：

- **G 代码 / NC**：`.nc` `.mpf` `.ptp` `.txt` `.gcode` 等，以及 SampleCode 无扩展名文件 → 直接载入编辑器
- **程序库 JSON**：合并到本地已保存程序列表

导入后会按文件名设置程序名，并自动解析；可再点「保存」写入程序库。

## 已导入示例库的 SampleCode 演示

以下程序已改编进 `src/lib/cnc/examples.ts`（`id` 以 `sf260-` 开头，加载时自动切到 SF-260H）：

| 示例 ID | 来源 | 说明 |
|---------|------|------|
| `sf260-sample-ortcp-c` | `SampleCode/ORTCP_C` | C 轴 0→90→180→270→0 |
| `sf260-sample-ortcp-a` | `SampleCode/ORTCP_B` | 原 B 轴摆角 → 仿真 A 轴 |
| `sf260-sample-ortcp-ac` | `SampleCode/ORTCP_BC` | A/C 联动姿态序列 |
| `sf260-sample-3plus2-drill` | `SampleCode/G81 G17` | A20° + G81 三点钻孔（行程收束） |

适配约定：

- 实机 **B → 仿真 A**；C 轴不变
- 坐标收束到约 **80×80×20** 工件包络，避免原样例超行程
- `G43.4` / `G68.2` / `G53.1` / `G49` 等未仿真指令改为注释保留
- 另有原内置演示：`sf260-5axis-pose`

## 若要继续落地 SampleCode

优先适配这几类，价值最高：

1. **RTCP 单轴/双轴**：`ORTCP_B`、`ORTCP_C`、`ORTCP_BC`（已部分导入）
2. **3+2 模板**：`TEST11`、其余 `G68.2 G8x` 系列
3. **解析器增强**：真正执行 `G43.4` / `G68.2` / `G53.1`，或支持读 B 字并映射到 A
